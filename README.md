# 🍔 Dev-Burguer API — Journey Backend (Etapa 1)

Este projeto foi desenvolvido como parte da **Journey Backend — Etapa 1** (PUC Minas / WebTech).  
O objetivo desta etapa é **construir uma aplicação simples com Node.js e Express**, consolidando fundamentos essenciais de back-end.

---

## Habilidades Desenvolvidas
- Compreensão do papel histórico e atual do **back-end**.  
- Criação de uma aplicação **Node.js + Express**.  
- Geração de **páginas HTML** pelo servidor.  
- Troca de dados com **formulários HTML**.  
- Criação de **rotas** e resposta a **requisições HTTP**.  

---

## Conhecimentos Envolvidos
- Fundamentos do protocolo **HTTP** (requisições, respostas, cabeçalhos, códigos de status).  
- Conceito de **servidor web** e geração de HTML via back-end.  
- Roteamento básico com **Express**.  
- Processamento de requisições com parâmetros via **path**, **query** e **body**.  
- Noções iniciais de **APIs REST** (rota GET retornando JSON).  

---

## Ferramentas Utilizadas
- **Node.js**  
- **Express.js**  
- **HTML, CSS e JavaScript**   

---

## ⚙️ Como Executar o Projeto
1. **Clonar o repositório**
   
   ```bash
   git clone https://github.com/wt-journey-backend-01/wt-journey-backend-01-etapa-1-BabiDoo
   cd wt-journey-backend-01-etapa-1-BabiDoo
   ```
2. **Instalar dependências**

   ```bash
   npm install
   ```

3. **Rodar o servidor**

   ```bash
   npm start
   ```

4. **Acessar as rotas**

   * Página inicial: [http://localhost:3000](http://localhost:3000)
   * Formulário de contato: [http://localhost:3000/contato](http://localhost:3000/contato)
   * Sugestões: [http://localhost:3000/sugestao](http://localhost:3000/sugestao)
   * API de lanches (JSON): [http://localhost:3000/api/lanches](http://localhost:3000/api/lanches)

---

## 📌 Funcionalidades Implementadas

* Servir arquivos estáticos via Express.
* Apresentar página HTML com **formulário de contato**.
* Processar dados do formulário e exibir resposta personalizada.
* Exibir páginas HTML geradas pelo servidor.
* Implementar rota que retorna **dados em JSON**.
* Diferenciar rotas de arquivos estáticos, páginas HTML e dados JSON.

---


## Observação

Esta etapa é **formativa e introdutória**, focada em entender o potencial do back-end para além das APIs, explorando renderização de páginas, controle de rotas e resposta a requisições.
